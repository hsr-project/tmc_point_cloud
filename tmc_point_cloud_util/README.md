ハイレベルアーキテクチャ
================
* 特になし

振る舞い
================
### PlaneSegmenter
* 平面検出クラス
基本処理はpclで行っているが、inlier,outlierの抽出、平面に対してある点と同じ方向にあるoutlierの抽出など便利メソッドを追加した。

### ClusterExtractor
* クラスタリングクラス
ポイントクラウドに対してクラスタリングを行う。これも基本処理はpcl。ある点に一番近いクラスタに属するポイントクラウドを抽出するといった便利メソッドを追加した。

### NormalEstimater
* 法線抽出クラス
ポイントクラウドに対して法線検出を行う。これも基本処理はpcl。ある点にの法線のみ抽出する機能を追加した。

### MeshConstructor
* メッシュ生成クラス
ポイントクラウドからメッシュを生成する。

### RayCastingUpsampling
* レイキャストアップサンプリングクラス
レイキャストでアップサンプリングを行う。

### util.hpp
* その他便利関数
そのうち名前を変えるかもしれません。

### point_cloud_recorder
* 発行されているポイントクラウドをPCDファイルへ保存する。

### static_point_cloud_publisher
* PCDファイルからポイントクラウドを読み取り、固定座標系に対して発行し続ける。

### dynamic_point_cloud_publisher
* static_point_cloud_publisherと似ているが，任意の座標系に対して固定された。
ポイントクラウドを任意の座標系から出力できる。
* 透視投影変換が崩れる（RGB値と距離値の対応がおかしくなる）ので注意。
